# Amazon Clone Website

A responsive Amazon homepage clone built with HTML and CSS, recreating the look and feel of Amazon's main page.

## 🚀 About the Project

This project is a front-end clone of Amazon's homepage, designed to practice and demonstrate HTML and CSS skills. It includes various sections like navigation bar, hero section, product categories, and footer - all styled to closely match Amazon's design.

## 📋 Features

- **Responsive Navigation Bar** - Amazon-style header with logo, search bar, and user options
- **Hero Section** - Eye-catching banner with promotional content
- **Product Categories** - Grid layout showcasing different product categories
- **Clean Layout** - Organized sections mimicking Amazon's homepage structure
- **Modern CSS** - Uses CSS Grid, Flexbox, and modern styling techniques

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Styling, layout, and responsive design
- **Images** - Product and category images

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Jatinmotwani17/Amazon--clone-website.git
   ```

2. Open the project folder:
   ```bash
   cd Amazon--clone-website
   ```

3. Open `practice.html` in your web browser to view the website.
